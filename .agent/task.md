## Key Design Decisions

### Color Palette
- **Primary Background:** #FAF8F5 (warm cream)
- **Secondary Background:** #F5F2ED (ivory)  
- **Text Primary:** #1A1A1A (charcoal)
- **Accent:** #C45C3E (terracotta)

### Typography
- **Display Font:** Playfair Display (elegant serif)
- **Body Font:** Inter (clean, modern sans-serif)
- **Mono Font:** JetBrains Mono (technical elements)

### Animation Philosophy
- Subtle, refined micro-interactions
- Smooth easing (cubic-bezier)
- Scroll-triggered reveals
- Minimal but impactful
